`.loaf/index.json` is derived state. It is regenerated by `writeIndex` after any mutation — `loaf.record_learning`, `loaf.add_crumb`, `loaf.bake`, CLI `add`/`bake`/`prune`/`reindex` all call it. Never hand-edit. If it gets out of sync, run `loaf reindex`.

Paths inside the index are stored repo-relative for portability — an absolute path would poison the file for collaborators who clone into a different directory. `writeIndex` rewrites paths with `path.relative(repoRoot, ...)` before serialization; `readIndex` returns the JSON as-is. Any code that consumes index paths must resolve them against `repoRoot` before touching disk.
